# Changelog

## 1.1.0

A content update focused on new Create addons, storage automation and Curios relics.

### New mods

**Create addons**
- Create: Connected, Create Connected Encased, Create Encased
- Create Propulsion, Create Aeronautics Toolgun
- Create Diesel Generators (adds oil deposits to world generation)
- Create: Deep Dark, Create Ender Transmission
- Create Components and Additions, GnKinetics, Escalated

**Storage & automation**
- Applied Energistics 2, Create Applied Kinetics, GuideME (AE2 dependency)

**Relics & Curios**
- Reliquified Artifacts, More Relics

**Quality of life**
- No Enderman Grief

### Changes
- MoreCulling is now client-only.
- Shaders are disabled by default (Iris menu to enable).
- Distant Horizons default client render radius lowered to 128 chunks.
- ModernFix dynamic resources enabled.
- Default configs added for all new mods.

### Notes
- New world generation (AE2 meteorites, oil deposits, Deep Dark content) only appears in newly generated chunks.
- Server: replace the whole `mods` folder; keep existing server configs and only add configs for the new mods.

## 1.0.0

First release.

- Based on Create+ 6.0.0 Alpha f (Minecraft 1.21.1, NeoForge 21.1.256), with every Create+ mod kept.
- Added Curios and Curios-compatible addons, extra Create addons, maps, waystones, voice chat and quality-of-life mods.
- Distant Horizons, SSRD, Iris and Colorwheel are optional on the client.
