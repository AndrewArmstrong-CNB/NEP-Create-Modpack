NEP Create Modpack 1.1.0 - servidor no AMP (CubeCoders)
=======================================================

PARTE 1 - Gerar o zip do servidor (no seu PC Windows)
 1. Extraia esta pasta em qualquer lugar do PC.
 2. Clique com o botao direito em gerar-pacote-amp.ps1 > "Executar com o PowerShell".
    Ele baixa os 164 mods do Modrinth, confere o SHA1 de cada um e junta com a pasta config
    (so as configs dos mods NOVOS da 1.1.0, para nao sobrescrever o que voce ja ajustou no servidor).
 3. No final aparece o arquivo NEP_Create_Modpack_AMP_1.1.0.zip, com as pastas mods e config na raiz.

PARTE 2 - Preparar a instancia no AMP
 (os nomes dos menus podem variar um pouco conforme a versao do AMP)
 1. Pare o servidor. Faca BACKUP do mundo (AMP > Backups, ou copie a pasta world).
 2. Configuration > Minecraft > Server and Startup:
      Server Type: NeoForge
      NeoForge version: 21.1.256 (Minecraft 1.21.1)
 3. Configuration > Java and Memory:
      Java: 21
      Memoria: 6 a 8 GB
 4. Volte ao Status e clique em Update, para o AMP instalar o NeoForge 21.1.256.

PARTE 3 - Enviar os mods e configs
 1. Abra o File Manager da instancia e entre na pasta do servidor
    (a que tem server.properties e a pasta world).
 2. Renomeie a pasta mods antiga para mods_backup (ou apague, se ja tem backup).
 3. Faca upload do NEP_Create_Modpack_AMP_1.1.0.zip nessa mesma pasta.
    Se o upload pelo navegador for lento ou falhar, use o SFTP do AMP
    (o endereco e a porta aparecem na instancia).
 4. Clique com o botao direito no zip > Extract. Nao deve haver conflito na config
    (o zip so traz arquivos novos); se o AMP perguntar, pode substituir.
 5. Apague o zip depois de extrair.
 6. Inicie o servidor e acompanhe o console. Na primeira inicializacao demora mais.

Se der erro ao iniciar, copie o log (logs/latest.log) para conferir.
